2. Install

Run MaterialUnigramSetup.exe. It installs for your account only, so Windows does not ask for administrator rights. Windows may warn that the publisher is unknown, because the installer is not code-signed; choose More info, then Run anyway if the file hash matches the one on the download page.

[SCREENSHOT: INSTALLER FROM THE BUILT PACKAGE]
Check the hash in PowerShell
Get-FileHash .\MaterialUnigramSetup.exe -Algorithm SHA256

3. Link your phone

Open the app on your phone, go to Settings, then Devices, then Link desktop device, and scan the code shown in the setup wizard.
